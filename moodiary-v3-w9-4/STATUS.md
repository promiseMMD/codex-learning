# W9.4 手机原生月度工作台

接续 W9.3 最终验收提交 `766dce17069ce7b502eb1cf9b16c58c418ed4dd5`，
分支 `moodiary-v3-w9-4-native-month-20261107`。本轮代码进入自动验收，尚未放行安装包。

## 本轮范围

- 长期主题页默认打开新的手机月度工作台；置顶主题的追加按钮进入相同块模型。
- 与 PC 共用 W9 SQLite 表、块 ID、修订父版本及幂等操作，不再创建旧版子日记。
- 月份选择、按日分组、月份正文搜索、每次 50 条展示、唯一总结默认折叠。
- 复用原生 MoodiaryEditor 的富文本正文，独立标题栏及日记元数据在块编辑页隐藏。
- 保存前获取带请求 ID 的编辑器当前文档快照；超时、未就绪、未来格式均拒绝保存。
- 新建/编辑、跨月移动、删除/恢复保持相同 Block ID，正文编辑保留事件毫秒及归档日期。
- 手机与 PC 保存后相互发送失效通知；通知不重写打开的草稿。
- 旧父版本拒绝覆盖；草稿保留并允许主动复制 JSON。
- 保存结果未知时锁定整份请求，以原操作/修订/正文重试，不能悄悄换父版本。
- 读取/格式校验失败使匹配缓存转为只读，复验成功后恢复写入。
- 旧版记录仍可单独浏览/编辑，未自动迁移；所有新块明确显示仅本机保存。
- 新界面字符串通过 slang 的中英命名空间生成；版本号为开发包 `2.9.2+99`。

## 验收

- 本地 TypeScript 类型检查及针对编辑器快照、原有桥接/视口的 23 项测试通过。
- 生产原生编辑器资源正常构建。
- CI 必须继续通过原版编辑器完整前端测试、W9.3 生产浏览器场景、原生编辑器生产
  Chromium 回执/富文本/标题隔离/未来格式场景，以及新增 Flutter 控制器/组件测试。
- 新增实际 HTTP 与手机适配器交叉写入测试；仍运行旧数据迁移、真实文件数据库、
  既有应用和 WebDAV 回归。全部通过后再以完整 Flutter/Rust 流程构建 ARM64 APK。
- CI 中生成的 slang 文件须一并保存在本分支，不能只依赖临时生成结果。
- 自动化不等于 Android WebView/输入法和 HyperOS 锁屏的真机验收。

## 尚未完成及后续顺序

W9.4 完成的是手机原生块工作台。以下功能继续明确保留为未完成：

1. **W9.5 原生日记列表投影**：每月创建真实原生 Diary、默认显示开关、最近 3 块预览及
   专用编辑跳转。投影进入普通同步/导出路径前必须具备逐实体保护，避免只备份可读
   正文而漏掉块历史、墓碑和关联。本轮不创建可能被误当成完整备份的投影。
2. **W10 完整备份/恢复与 WebDAV**：Topic/Month/Block/Revision/Head/Operation、
   墓碑、附件的完整归档、哈希验证、隔离恢复、同步门禁、双头合并及冲突解决界面。
3. **新块持久化草稿**：当前只保护打开的编辑页，并支持主动复制草稿；手机进程被杀、
   页面刷新或浏览器崩溃后的自动恢复尚未实现。
4. **历史迁移及主题管理**：旧子日记非破坏转换、快照/映射/幂等/回滚；主题改名归档、
   同名检查、内部标记与用户标签分离；PC 新建/管理主题。
5. **独立块标题及媒体**：块标题字段、列表/表格等更多原生格式、图片上传 UI、月度块
   附件、文件/DB 持久化操作日志、强杀恢复及孤儿文件校验。
6. **全局搜索、日历与时区**：新块接入完整索引；主题 IANA 时区、夏令时/旅行/午夜边界。
7. **最终放行**：10,000 块/3,000 日记性能基准、完整回归、稳定签名和连续覆盖升级、
   双设备离线并发/新设备恢复、HyperOS 3 与 Android 16 真机锁屏及网络切换验证。

完整长期清单仍见 `moodiary-v3-w9-3/DEVELOPMENT_PLAN.md`；不能将 W9.4 原生编辑
等同于 W9.5 列表投影、W10 云同步或最终 RC 已完成。
