# Moodiary Long-Record Alpha build

This isolated branch builds a modified Moodiary Android APK from upstream commit `2c552ddd7939a054122380397fb914cf000824b0`. The original `main` branch is unchanged. The mod source is packaged in `build-payload.b64` and unpacked by CI. This is a test APK only and uses the ephemeral debug signing key unless configured otherwise.

AGPL-3.0, upstream <https://github.com/ZhuJHua/moodiary>.
